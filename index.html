海外广告与新平台情报

2026-08-07｜广告 AI 正从“帮人生成素材”进入“直接调用投放系统”：Amazon 用 MCP 把自然语言连接到建活动、报表与跨市场扩展；Google 同时把视频资产适配和搜索活动迁移推向更自动化的工作流。

今日总判断

推断下一阶段的投放优势不只是“会写 prompt”，而是把可执行权限、事实资产、审批和测量边界一起产品化。Amazon Ads MCP Server 已能把自然语言转为结构化 API 调用，并提供建活动、报告、跨地区扩展等多步工具；Google 则在 Demand Gen 中增加素材变形与 Web-to-App 获客测量。团队应把“生成—审核—发布—归因”视作一条受控流水线。【来源】Amazon Ads：MCP Server 开放测试、Google：Demand Gen 6 月更新

推断媒介与素材也在同步重组：LinkedIn 的职业人群信号可经 Amazon DSP 购买美国 CTV 库存；Google 将为 Demand Gen 提供更多跨比例视频变形。一个母版不再够用，品牌需要按屏幕、观看距离、声音环境与转化路径预设资产模块。【来源】Amazon Ads × LinkedIn：CTV 合作、Google：Demand Gen 视频增强

  • 事实Amazon Ads 2 月宣布其 MCP Server 进入全球 open beta，面向拥有有效 API 凭证的 Amazon Ads 合作伙伴；它可连接 Claude、ChatGPT、Gemini 或自建 Agent，并访问建改删活动、报表、账户设置及账务等能力。官方同时强调，连接本身不保证可靠结果，部分工具会把多步操作编排为需人工审核的待发布活动。【来源】Amazon Ads 官方公告，2026-02-02
  • 事实Amazon Ads 与 LinkedIn 5 月宣布：美国广告主可在 Amazon DSP 通过 deal-based buying 购买 LinkedIn CTV Ads，使用 LinkedIn 的职位、行业、资历等第一方受众信号，并与 Amazon 受众放在同一活动中；流媒体库存经 Microsoft Monetize 提供。公告未给出活动效果基准。【来源】Amazon Ads 与 LinkedIn 联合公告，2026-05-07
  • 事实Google 6 月 25 日公布 Demand Gen 更新：视频增强将支持更多比例互转，包括竖屏转方形/横屏、方形转横屏；Gemini 将在选取图像与视频时给出创意优化建议；Web to App Acquisition Measurement 已可衡量由网页路径带来的新 App 用户安装。【来源】Google Ads 官方更新，2026-06-25
  • 事实Google 对 AI Max 迁移时间作过修订：DSA 的 sunset 与自动升级延至 2027 年 2 月开始；Automatically Created Assets 与 campaign-level broad match 仍计划自 2026 年 9 月起自动升级至 AI Max。广告主应按更新后的两条时间线分别盘点。【来源】Google Ads 官方公告及 2026-06-11 更新

B2B 人群进入 CTV

事实LinkedIn CTV × Amazon DSP 把职业属性和流媒体库存接到同一购买链路，目前公告明确的是美国市场。适合 B2B 品牌测试“电视触达—站内再营销—销售线索”的组合，但官方未披露统一归因模型。【来源】Amazon Ads × LinkedIn（单一公告，需后续验证）

搜索活动进入迁移窗口

推断9 月前优先核查 ACA 与 campaign-level broad match，而不是误把全部 DSA 当成同时下线；迁移测试需冻结预算和主要落地页，单独观察查询覆盖、URL 扩展与转化质量。【来源】Google：AI Max 迁移说明

广告素材与创意资产

素材平台 / 工具动态

  • 事实Google 表示 Demand Gen 将支持更广的视频比例转换，并计划由 Gemini 在资产选择环节给优化建议；公告没有承诺每个账户已即时获得全部功能。【来源】Google Ads：Demand Gen Drop
  • 事实Amazon MCP Server 的价值并非直接生成画面，而是让 Agent 调用活动与报告能力；素材生产系统可以与投放系统衔接，但权限与批准仍需由广告主设计。【来源】Amazon Ads：MCP Server

素材趋势或格式变化

  • 推断CTV 母版要为“远看”设计：前 3 秒只保留一个人群场景、一个视觉主角和一句主张；中段用产品界面/使用动作解释机制，结尾用短 URL、品牌搜索词或二维码承接。LinkedIn CTV 的公开公告没有展示具体品牌素材，以上是基于其 CTV 购买场景提出的测试框架，不是平台规范。【来源】Amazon Ads × LinkedIn：CTV 场景
  • 推断比例转换不等于简单裁切：竖转横时需要重排人物、字幕安全区、产品露出与 CTA；若自动变形遮挡包装文字或证明点，应回退到人工版本。【来源】Google：Demand Gen 比例转换

可执行素材测试建议

  • 推断16 格母版：2 个 Hook（痛点/结果）×2 个首帧（人/产品）×2 个证明点（演示/第三方证据）×2 个 CTA（了解/试用）；为 9:16、1:1、16:9 各设字幕安全区。固定受众、出价与落地页，比较 3 秒观看、有效访问、App 安装或线索质量。【来源】Google：跨比例资产与 Web-to-App 测量
  • 推断Agent 发布闸门：限制 Agent 只建草稿；预算、国家、品牌词、否定词、落地页、像素/SDK 与删除动作必须二次审批。每次执行保存 prompt、API 动作、差异和批准人。【来源】Amazon：多步工具与 review/approval

案例深拆

BODi × Acadia × Amazon Ads：用分层人群与视频切入蛋白粉类目

事实品牌/产品、人群与场景：BODi 是健身与营养品牌；其官方商店销售 Shakeology 等营养产品。Amazon 案例称，团队在美国蛋白混合粉类目按漏斗分层：上层触达健身兴趣与新客，中层覆盖弃购与再互动人群，下层经营复购及高价值买家。【来源】Amazon Ads 案例页、BODi 官方商店

案例观察商业目标与核心洞察：公开目标是进入新类目、提升份额与品牌可见度，同时维持盈利；核心做法不是单纯加预算，而是用 Amazon Marketing Cloud 为漏斗阶段建立自定义人群，再按新客贡献调整预算。【来源】Amazon Ads 案例页、BODi 官方商品体系

事实创意概念、素材拆解与媒介：媒介组合包括 sponsored ads、online video 与 display，线上视频用于上层获客；公开案例未提供可逐帧核验的真实广告，因此本期不编造首帧、Hook、画面、文案、产品露出、证明点或 CTA。可确认的产品承接是 BODi 官方商店商品页。【来源】Amazon Ads 案例页、BODi 官方商店

数据转化路径与结果信号：公开路径为视频/展示触达 → sponsored search/商品页 → 购买与复购。Amazon 案例引述 BODi 的 2024–2025 美国数据：蛋白混合粉类目份额从 0.1% 到 0.9%，新客占比从 25% 到 78%，online video 的新客贡献率为 80%。这些是平台案例中的品牌自报口径，未见独立审计，不能外推为预期 ROAS。【来源】Amazon Ads 案例页（数据来源标注为 BODi, U.S., 2024–2025）、BODi 官方商店

推断可复用打法：先按“新客—弃购—复购”建互斥人群；用视频测试类目教育，再将预算转向能带来新增而非只收割品牌词的组合。风险与本地化：营养品素材需逐市场审查功效主张、成分、免责声明与订阅条款；跨平台新客定义和归因窗口必须对齐。【来源】Amazon Ads：人群分层与预算调整、BODi 官方商品页

国内打法补充

  • 推断直播电商常用的“场景—演示—证据—异议—CTA”可迁移成海外短视频母版，但营养、美妆、金融等品类必须把强功效话术改为当地可证实声明，并让落地页首屏复述同一证明点。【来源】Google：Demand Gen 资产适配、BODi 官方商品承接示例
  • 推断国内团队常见的日报自动化可进一步升级为“建议—草稿—审批—执行—复盘”五段式 Agent 流程；对预算、账户、删除和账务数据设置最小权限，避免把自然语言便利等同于安全授权。【来源】Amazon Ads：MCP 能力及人工批准

今日可执行小实验

  1. 推断3 比例同源测试：选一条竖屏胜出素材，制作人工 1:1 与 16:9 版本；保持 Hook、证明点、CTA 与落地页一致，对照平台自动变形版本，检查字幕、包装与有效访问。【来源】Google：Demand Gen 视频增强
  2. 推断B2B CTV 路径草图：以一个高价值职位人群设计 15 秒 CTV → 品牌搜索/二维码 → 行业落地页 → 再营销 → demo 的链路；先定义曝光后搜索、访问与合格线索，不把 CTR 当唯一成功指标。【来源】Amazon Ads × LinkedIn：美国 CTV 受众购买
  3. 推断AI Max 迁移清单：导出当前 ACA、campaign-level broad match、DSA 活动，分别标记 2026-09 与 2027-02 的处理窗口；为前两项建立 14 天对照，监测查询、URL、转化价值及无效线索。【来源】Google：修订后的迁移时间
