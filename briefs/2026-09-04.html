海外广告与新平台情报

2026-09-04｜搜索广告正在同时发生两层自动化：媒体侧扩查询、改文案与选落地页；团队侧用 Agent 做投前研究，但上线权仍应留给人。

Microsoft AI MaxAdvertising MCPAgent 工作流

今日总判断

推断AI 搜索投放的竞争单位正从“关键词 + 一条广告”转成“可被模型读取的页面、受控的资产库、完整转化信号与人工审批链”。Microsoft AI Max 已把查询扩展、文字定制和最终 URL 扩展放进标准搜索广告；Realtor.com 则把竞品关键词研究接进 Claude Agent。两者共同提示：先把事实、页面和审核权整理好，再扩大自动化边界。【来源】Microsoft Advertising：AI Max，2026-08-27、Microsoft Advertising：Realtor.com 案例，2026-08-14、Realtor.com Tech Blog：AI 工作方式

海外重点信号

  • 事实Microsoft Advertising 于 8 月 27 日宣布 AI Max 在标准 Search campaigns 中可用，三项核心能力是 search term matching、text customization 与 final URL expansion；同时提供搜索词/资产报告、品牌控制与词项排除。它是可选功能，并非所有账户自动开启。【来源】Microsoft Advertising 官方发布、Microsoft Advertising 8 月产品汇总
  • 数据Microsoft 称，44 个由广告主运行、预算与出价策略保持一致的 A/B 实验中，开启 AI Max 的花费加权转化提升约 13.6%；其中只有 10 个实验在转化或转化价值上达到统计显著正向。该结果是 Microsoft 内部数据，不能外推到单个账户。【来源】Microsoft Advertising 官方发布及脚注 4（平台自报，单一结果来源，需后续验证）
  • 事实Google 已把 Dynamic Search Ads 自动升级推迟到 2027 年 2 月开始；但使用 automatically created assets 或 campaign-level broad match 的合资格 Search campaigns 仍计划从 2026 年 9 月起升级至 AI Max。Microsoft 则说明 DSA 将继续支持，且从 Google 导入的对应设置不会直接变成 Microsoft AI Max。【来源】Google Ads 官方更新，更新于 2026-06-11、Microsoft Advertising 官方说明
  • 事实Realtor.com 把 Microsoft Advertising MCP 的 auction insights 接入 Claude agents，用共享 prompt/skill 库生成关键词机会，再依次路由给搜索营销人员讨论和第二位审核者验证，任何 campaign change 上线前都保留人工批准。【来源】Microsoft Advertising 官方案例、Realtor.com Tech Blog：营销团队的数据与 Agent 工作

新广告平台与 AI 原生广告

查询不再等同于一个关键词

事实Microsoft 说明，AI 驱动的消费者 prompt 可能触发多次底层搜索；AI Max 会结合关键词、广告、落地页与上下文寻找复杂或对话式查询。【来源】Microsoft AI Max 官方说明

广告素材延伸到页面事实

推断当平台可以改写文字并选择最终 URL，网页标题、首屏卖点、库存/价格、合规声明和页面间一致性都成为“素材输入”。页面质量差会同时伤害匹配、文案与承接。【来源】text customization 与 final URL expansion 说明

Agent 先做低风险研究

案例观察Realtor.com 从关键词与 auction insights 研究起步，而不是让 Agent 直接调预算；这是可审计、可回退、价值明确的入口。【来源】Realtor.com 官方案例、Realtor.com Tech Blog

广告素材与创意资产

素材平台 / 工具动态

  • 事实AI Max 的 text customization 会使用现有广告资产与网站内容生成并测试更多消息变体；final URL expansion 会为查询选择更合适的承接页。广告主可查看资产和搜索词报告，并使用品牌、词项与 URL 控制。【来源】Microsoft AI Max 官方发布
  • 事实Realtor.com 的共享 prompt 与 skill 库用于复用有效分析方式；公开案例只描述关键词研究与审阅流程，没有公开真实广告文案、图片或视频素材，因此本期不虚构其素材画面。【来源】Realtor.com 官方案例

素材趋势或格式变化

  • 推断从写满标题转向建立“事实模块”：每个产品准备受众问题、核心利益、规格/价格、证明、限制条件与对应 URL；让生成式文案只能重组已核验模块。【来源】AI Max 的资产与页面输入机制
  • 推断从一次性分析转向可复用研究资产：把竞品词、否定词、品牌约束与审批规则写成版本化 prompt/skill，而不是散落在个人聊天记录。【来源】Realtor.com 的共享 prompt/skill 库

可执行素材测试建议

  • 推断Hook / 标题：测试“任务结果”对“具体障碍”两种首句，例如“更快找到合适房源”对“库存少时如何扩大选择”；描述行固定一个可核验证明与一个限制条件。【来源】Microsoft text customization 输入说明
  • 推断脚本 / 视觉资产：若扩展到多媒体，沿用“问题—产品演示—证明—异议处理—CTA”五段；前 3 秒只展示一个任务和产品界面，不叠加多个卖点。真实 Realtor.com 案例未公开视觉素材，此结构是测试建议而非案例复原。【来源】案例仅公开工作流边界、Realtor.com 官方产品页
  • 推断UGC / 达人角色：SaaS 或平台型产品可让“新手、重度用户、管理员”各演示同一任务；固定产品事实、品牌词与禁止承诺，只改变角色、Hook 和使用场景。【来源】Realtor.com 对 AI 输出需人工专业判断的工作原则
  • 推断产品展示 / 证明 / CTA / 承接：首屏复现广告中的任务词，展示一次真实操作与可验证证明；CTA 测“查看结果”对“开始搜索”。开启 URL expansion 时，每周抽检查询—文案—页面三联单，并单列错页率与品牌违规率。【来源】AI Max final URL expansion、报告与控制说明
  • 推断可变体测试项：只在同一轮改变一类变量：①匹配开/关；②文字定制开/关；③URL 扩展开/关；其余预算、出价、地域和转化定义固定，至少同时监控增量转化、查询质量、错页与线索后端质量。【来源】Microsoft 44 个 A/B 实验的控制方式与三项功能

案例深拆

Realtor.com × Microsoft Advertising MCP：把关键词研究变成 Agent 流水线

事实品牌/产品、人群与场景：Realtor.com 是美国房地产搜索平台；使用场景是搜索营销团队从 Bing auction insights 中寻找竞争性关键词机会。商业目标：缩短跨工具取数、审阅和路由时间，并在不增加专门数据科学资源的情况下扩展研究。【来源】Microsoft Advertising 官方案例、Realtor.com Tech Blog、Realtor.com 官方产品页

案例观察核心洞察：高价值瓶颈并非生成更多文案，而是更快把平台数据变成可审阅机会。创意概念：“Agent 做研究，人做决定”。广告素材拆解：公开材料未展示真实投放素材，因此首帧/Hook、画面、产品露出、证明点、CTA 与素材格式均为未公开；不能据工作流案例反推广告内容。【来源】Microsoft Advertising 官方案例、Realtor.com Tech Blog

事实媒介/平台组合：公开范围只有 Microsoft Advertising Search、auction insights、Advertising MCP 与 Claude agents；未披露其他媒体预算。转化路径：Agent 读取数据并生成建议 → 搜索营销人员讨论 → 第二位审核者验证 → 人工批准后才可能改 campaign；公开资料没有消费者点击或购房转化漏斗。【来源】Realtor.com 官方案例

数据结果信号：案例称洞察由过去需要数天缩短到数分钟，并能一次审计数万关键词；页面没有公开样本期、准确率、节省工时、媒体效率或业务转化。因此这些只作为平台/客户自报的流程信号，不作为 ROAS 结论。【来源】Microsoft Advertising 官方案例（单一结果来源，需后续验证）

推断可复用打法：先选“只读、可核验、重复高”的任务；定义输入字段、输出格式和禁止动作；建立共享 prompt/skill；设置经办人与复核人；记录采纳率、误报率和从发现到上线的周期。风险与本地化：房地产广告涉及公平住房、地域与受众合规；竞品词也可能有商标和品牌安全风险。跨市场复制前应重新核对当地广告政策、数据权限与人工审批责任。【来源】案例的人审与低风险起步建议、Realtor.com：AI 输出需核验合规与事实

国内打法补充

推断国内团队可迁移的是“数据只读接入—Agent 产出候选—两级人工复核—平台执行”的治理结构，可用于抖音/巨量、腾讯广告或电商搜索词日报；不能把 Microsoft MCP、auction insights 或 AI Max 的能力名称直接等同于国内平台产品。先从否定词候选、素材标签和落地页错配检查起步，比自动改预算更安全。【来源】Realtor.com 案例工作流、Realtor.com 的人工核验原则

今日可执行小实验

  1. 推断选一个非品牌 Search campaign，复制为实验组；只开启 search term matching，保持预算、出价、地域与转化目标一致。记录新增查询、否定词率、有效转化和后端质量，避免一次开启三项后无法归因。【来源】AI Max 功能及 A/B 实验口径
  2. 推断建立 20 条“查询—允许卖点—证明—禁用表述—唯一承接页”事实表，让 Agent 只生成建议，不写回账户；由经办人与复核人分别标注采纳/拒绝原因。【来源】共享 prompt/skill 与双层人审流程
  3. 推断对 30 个 AI 扩展查询逐条检查页面首屏：是否重复查询意图、是否在 5 秒内出现产品、证明点与 CTA、是否出现错误价格/地区。把错页率作为与 CPA 同级的守门指标。【来源】final URL expansion 与 URL 控制说明
